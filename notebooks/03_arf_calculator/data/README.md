# Data — ARF Calculator

## No external data required

This notebook does not require external data downloads. All ARF equation coefficients and regional parameters are implemented directly from ARR 2019 Book 2, Chapter 6.

## Validation data

The 11 test cases from ARR Book 2 Chapter 6.5.3 are hardcoded in the notebook for validation purposes.

## Generated outputs

The notebook generates ARF matrices suitable for use as URBS design rainfall inputs. These can be exported as CSV:

```
data/
└── arf_matrix_output.csv     # generated by notebook
```
