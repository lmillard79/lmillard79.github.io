# Data — ARR Temporal Pattern QA

## Data source

Temporal patterns are retrieved directly from the ARR Data Hub API in the notebook. No manual data download is required.

The API endpoint returns temporal patterns for a specified location (latitude/longitude), duration, and AEP. The notebook demonstrates how to retrieve and screen patterns for a sample location.

## Cached patterns (optional)

If you are running the notebook offline or want to avoid repeated API calls, you can cache the API response here as a JSON file. The notebook includes an option to load from cache.

```
data/
└── patterns_cache.json     # optional — generated by notebook
```
